Sur le profil, cliquez sur « Suivre ce profil ». Suivre est **gratuit** : vous voyez les publications gratuites de la personne dans votre fil.

- **Profil public** : le suivi est immédiat, le bouton devient « Abonné ».
- **Profil privé** : le bouton affiche « Demande envoyée » jusqu'à ce que la personne accepte. Vous pouvez annuler la demande.

**Ne plus suivre** : « Se désabonner » depuis le profil.

Suivre un coach **ne donne pas accès à son contenu premium** : c'est un abonnement payant distinct — voir la fiche « S'abonner au contenu premium d'un coach ».
