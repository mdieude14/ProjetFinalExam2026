**Seuls les coachs certifiés peuvent organiser un événement.** Si le bouton « Créer un événement » n'apparaît pas, faites d'abord vérifier votre diplôme.

**Créer** : « Événements » → « Créer un événement ». Renseignez le titre, la description, le sport, la date de début, la ville, le code postal, l'adresse du rendez-vous et, si besoin, le nombre de places (vide = sans limite). « Position sur la carte » → « Utiliser ma position actuelle » place l'événement sur la carte. Ajoutez une affiche si vous le souhaitez, puis « Créer l'événement ».

**Visibilité** : « Ouvert à tous », ou « Réservé à mes abonnés premium » — l'adresse exacte n'est alors visible que de vos abonnés.

**Modifier** : sur la page de l'événement, « Modifier », puis « Enregistrer ».

**Annuler** : « Annuler l'événement ». Le motif est facultatif, mais **il est lu par les inscrits** : précisez-le (météo, blessure, inscrits insuffisants…). Les inscrits sont informés sur la page de l'événement. En tant qu'organisateur, vous n'avez pas à vous inscrire : vous y êtes déjà attendu.
