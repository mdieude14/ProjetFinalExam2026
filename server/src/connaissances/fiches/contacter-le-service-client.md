L'assistance est accessible depuis **n'importe quelle page** : le bouton rond en bas à droite, « Ouvrir l'assistance ». Le panneau qui s'ouvre propose deux entrées.

**« Contacter le support client »** — pour un problème, une réclamation ou une demande à l'équipe. Renseignez un **objet** (par exemple « prélèvement en double »), décrivez votre demande, puis « Envoyer au support ». Votre demande reçoit une **référence**.

**« Question d'utilisation »** — pour savoir comment faire quelque chose sur CoachConnect. L'assistant traite la question dans le panneau.

**Le support vous écrit par courriel**, à l'adresse de votre compte — pas dans le panneau. Une fois le courriel parti, l'assistance affiche un encadré « Une réponse vous a été envoyée par e-mail », avec la date et la référence : c'est le signe qu'il faut regarder votre boîte de réception.

Une demande qui relève d'une **décision** — remboursement, litige, signalement — est toujours confiée à un membre de l'équipe.

**Sur Telegram**, l'assistant traite aussi les questions d'utilisation, ainsi que vos abonnements et inscriptions si vous avez rattaché votre conversation. Pour une réclamation, passez par « Contacter le support client ».
