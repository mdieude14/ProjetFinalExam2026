**Écrire à quelqu'un** : sur son profil, « Envoyer un message ». Vos conversations sont dans le menu « Messages ».

**La règle des demandes** : si la personne vous suit déjà, la conversation s'ouvre directement. Sinon, votre premier message part comme une **demande** : les suivants attendent qu'elle l'accepte. Le message « Vous pourrez écrire de nouveau lorsque votre demande aura été acceptée » s'affiche en attendant.

**Recevoir une demande** : la conversation affiche « … souhaite vous écrire » avec « Accepter » ou « Refuser ». Une conversation refusée n'accepte plus aucun message.

**Photos et vidéos** : le bouton de pièce jointe permet d'« Importer une photo ou une vidéo » ou de « Prendre une photo ». Images jusqu'à 5 Mo, vidéos jusqu'à 25 Mo.

**Aimer un message** : « Aimer ce message » ; « Retirer mon like » pour l'annuler.

Entrée envoie le message ; Maj + Entrée passe à la ligne.
