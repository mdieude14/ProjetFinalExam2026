L'assistant de CoachConnect répond aussi sur Telegram, au compte indiqué dans Paramètres, section « Assistant sur Telegram ». Sans rien configurer, il répond aux questions sur l'utilisation de l'application.

**Pour qu'il réponde aussi sur vos abonnements et vos inscriptions**, rattachez votre conversation : Paramètres → « Assistant sur Telegram » → « Générer un code ». La page affiche une commande du type « /lier ABCD2345 » : envoyez-la telle quelle au bot, dans votre conversation privée avec lui. La page confirme d'elle-même le rattachement, sans rien recharger.

Le code est valable **dix minutes et une seule fois**. S'il a expiré, générez-en un nouveau.

**Ce que l'assistant voit alors** : vos abonnements premium et vos prochaines inscriptions à des événements. Jamais un montant, un paiement ni votre adresse — pour cela, utilisez l'assistant de l'application. Le rattachement ne se fait qu'en conversation privée, jamais dans un groupe.

**Pour délier** : « Délier la conversation » dans les Paramètres, ou la commande /delier envoyée au bot.
